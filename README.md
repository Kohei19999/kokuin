# 刻印読み取りプロジェクト (Kokuin Reader)

工場などの製造現場において、金属部品に打たれた「刻印（文字や数字）」を画像認識で自動で読み取るシステムの開発を目指すプロジェクトです。

## プロジェクトの背景・目的
金属部品の刻印は、照明の当て方、金属の表面状態（反射、ザラつき）、汚れなどにより、単純な画像処理では認識が非常に困難です。
本プロジェクトでは、最終的な「刻印文字のAI認識」を達成するための第一歩として、まずは身近な「50円玉」を題材に、**「金属表面の模様と、貫通穴（ドリル穴）を見分ける画像処理パイプライン」**を構築しています。

詳細は `01_目的・背景/` フォルダ内のドキュメントを参照してください。

## フォルダ構成

プロジェクトは以下のステップに沿って整理されています。

- **`01_目的・背景/`**
  プロジェクトのゴールや、現場の課題感などをまとめたドキュメント。
- **`02_事前知識収集/`**
  画像処理に関する世界中（Reddit, StackOverflow等）のノウハウや技術調査のメモ書き。
- **`03_データ探し/`**
  テスト用の元画像データと、正解ラベル（CSV）。現在は50円玉の画像を格納。
- **`04_刻印の課題/`**
  金属刻印特有の難しさ（ハレーション、スミ入れなど）と解決策案のドキュメント。
- **`05_硬貨練習プロジェクト/`**
  AIを使わない「ルールベース（OpenCV）」によるアプローチ。
  照明ムラに強い「ブラックハット変換」や、形状で判定する「円形度フィルタ」などを組み合わせたカスケード判定器（`evaluate_real_holes.py`）を実装しています。
  各トライアルの実験結果（try_001〜）もここに保存されます。
- **`06_AI学習実装/`**
  ディープラーニング（YOLOv8など）を用いたアプローチの実験用コード。

## 現在の進捗（50円玉 穴の有無判定）

`05_硬貨練習プロジェクト/evaluate_real_holes.py` にて、以下の2段構え（カスケード判定）アルゴリズムを実装し、**テスト画像14枚に対し穴の有無判定 精度100%** を達成しました！

1. **絶対閾値判定:** 穴の「絶対的な暗さ」だけで確実な穴を高速に拾い、穴なしコインの誤検知を100%防ぐ。
2. **ブラックハット ＋ 円形度チェック:** 照明ムラで見えにくくなっている穴を抽出し、「丸いかどうか」で本物の穴を救済判定する。
