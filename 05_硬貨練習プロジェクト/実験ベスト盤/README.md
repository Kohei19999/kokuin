# 実験ベスト盤 README

## これは何？

50円玉の貫通穴の有無・ズレを OpenCV で検出するアルゴリズムの、**最終決定版（ベストプラクティス）**です。

実験フォルダ（try_001 〜 try_180+）の中から、以下の基準で厳選・整理したものです。

---

## 選定理由

| 指標 | 値 |
|---|---|
| 対象画像 | 30枚（多様な撮影条件） |
| 正解ラベル | Kohei 人間の感覚（微妙=0.5点） |
| 穴の有無 精度 | **86.7%** |
| 穴のズレ 精度 | **75.0%** |
| **総合精度** | **61.7%** |

> ※ ツギハギで過学習した最終試行（try_028）の総合精度は 35.0% まで落ち込んでいました。
> シンプルな物理法則ベースのルールに戻すことで 61.7% まで回復しました。

---

## 設計思想（KISS原則）

過学習してしまった反省から、以下だけに絞り込んでいます：

1. **コイン外周の検出**  
   `MedianBlur(9)` + `HoughCircles`（動的サイズ）  
   → CLAHEは使わない（背景ノイズを拾うため）

2. **穴の有無判定**  
   固定閾値 `THRESH_BINARY_INV < 60`（物理的な影の暗さ）  
   + ブラックハット変換の面積・円形度で補完  
   → 穴は必ず暗い、という物理法則のみを信用する

3. **穴のズレ判定**  
   穴マスクの重心と外周中心の距離比（`ratio > 0.08` でズレあり）

## なぜ 100% にならないのか

照明・撮影角度がコントロールされていない手持ち写真では、
ルールベース（OpenCV）は本質的に 60〜70% が限界です。

次のステップとして以下が考えられます：
- **ハードウェア対策**: テレセントリックレンズ + 均一照明（同軸落射）
- **ディープラーニング**: YOLOv8 等の学習ベース検出器
