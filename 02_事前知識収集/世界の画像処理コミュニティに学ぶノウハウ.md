## 1. コミュニティの黄金律：「照明が8割、画像処理が2割」

RedditやStack Overflowの画像処理スレッドで最も頻繁に強調される絶対的なルールです。

* **金属反射（Glare / Specular Reflection）の恐怖:**
  * 金属表面に光が反射して真っ白に飛んだ部分（白とび）は、**画像情報そのものが物理的に消失（飽和）**しています。ソフトウェア（OpenCV）でどんな高度なアルゴリズムを組んでも、消えた情報は復元できません。
* **コミュニティが推奨するハードウェア対策:**
  * **偏向フィルター（Polarizing Filter）:** カメラレンズ前に偏光フィルターを装着し、金属のギラつき（正反射光）を物理的にカットする。
  * **ドーム照明 / 拡散照明（Diffuse Lighting）:** ローアングルやドーム状の影を作らない光を当て、凹凸の「影」だけを際立たせる。

## 2. ギラつき・照明ムラを消す高度なOpenCV前処理テクニック

工場内の環境光や照明ムラがある状態で、金属表面の穴や刻印をくっきり浮かび上がらせるため、世界のエンジニアが使っている定番の手法です。

### 💡 割算による照明の平坦化（Division by Gaussian Background）
画像内の「照明のムラ」だけを抽出し、元画像を背景画像で割り算することで、**表面の影やムラを完全に平坦化（フラット化）**する手法です。

```python
# 1. 巨大なカーネルで重くぼかし、背景の「照明ムラ」だけを抽出
background = cv2.GaussianBlur(img_gray, (151, 151), 0)

# 2. 元画像を背景画像で割算（float32に変換して精度を維持）
img_float = img_gray.astype(np.float32)
bg_float = background.astype(np.float32)
normalized = cv2.divide(img_float, bg_float, scale=255)
result = np.clip(normalized, 0, 255).astype(np.uint8)
```

### 💡 ブラックハット変換（Black-Hat Transformation）
モルフォロジー演算の「ブラックハット変換（`cv2.MORPH_BLACKHAT`）」は、**「暗い背景の中にポツンとある小さな黒い穴や窪み」だけを強力に浮き彫りにする**処理です。
まさにドリル穴や刻印の検出に威力を発揮します。

```python
# 検出したい穴のサイズより少し大きいカーネルを定義
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (15, 15))

# 背景の大きな明暗差を無視し、小さな暗部（穴や凹み）だけを白い輝度として抽出
blackhat = cv2.morphologyEx(img_gray, cv2.MORPH_BLACKHAT, kernel)
```

## 4. 自動閾値（大津の二値化）の使いどころの知見

Stack Overflow等でよく議論される「大津の二値化（Otsu Binarization）」の限界と使い分けについての結論です。

* **大津の手法が最高に活きる場面:**
  * 「黒い背景に白い部品」「明るい表面に明らかな暗い穴」など、**明暗の2つの山（双峰性ヒストグラム）が確実に存在する画像の自動二値化**。
* **大津の手法を使ってはいけない場面:**
  * 「穴がない無地の金属表面（我々の `012` 番のようなエラー品）」
  * 画像内に暗い部分が存在しない場合、大津のアルゴリズムは**金属表面の微細な質感差を無理やり白と黒に切断してしまい、存在しない「偽のノイズや穴」を生み出す**。

**結論:** 
- 「有無の判定（0/1）」には**絶対閾値（固定値）**を使う。
- 「存在する物体の輪郭切り出し」には**大津の二値化（相対閾値）**を使う。
